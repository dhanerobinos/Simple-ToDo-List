# My First Project: Learning C# WinForms Applicatiob and MSSQL with a To-Do List App

Learning  C# WinForms and use of MS SQL Server as the database in my first project has been an eye-opener. 
Along this rather steep and winding path, I have learned useful information about Object-Oriented Programming (OOP), user interface events,
and direct interaction with databases. The project helped me in learning to access and manage the data and present it in a responsive and functional user interface.

- Adopting the OOP in my application played an important role in allowing code organization, clarity and encouraging modularity.
Using classes and objects, I was able to draw up the boundaries of separate concerns with regard to encapsulation of data and functionality. 
This has enabled me to create reusable elements and ensure that the codebase can be easier to maintain.

- Events were fundamental in developing an interactive application. I also got familiar with how to deal with user activities,
such as button clicks, key presses and item selections on a list so that the application was interactive. This further added 
to the interactive-ness of the user experience.

- Using MS SQL Server as the backend, I was able to store and manage task data persistently. I established database connections, wrote SQL queries, 
and performed CRUD operations (Create, Read, Update, Delete). By integrating these database actions directly with the UI, 
the application could display and modify data in real time.

- This project challenged me to solve real-world coding problems. I faced and overcame various issues related to logic,
UI design, and database connectivity. These moments helped strengthen my debugging skills, patience, and 
confidence in working through complex development challenges.

Building this To-Do List desktop app was an important step in my software development journey.
It gave me hands-on experience with C# WinForms, database integration, and OOP design principles. 
With this foundation, I look forward to growing further especially as I begin exploring web development 
using Entity Framework Core, Blazor, and .NET 8 in future projects.
